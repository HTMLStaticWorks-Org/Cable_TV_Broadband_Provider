CONNECTWAVE - CABLE TV & BROADBAND PROVIDER WEBSITE

Pages:
- index.html        Home1 (modern home page featuring prominent plans, speed tiers, coverage banner)
- Home2.html        Home2 (alternative modern layout with plans, service highlights)
- plans.html        Full broadband & cable TV plans with category filters and comparison matrix
- coverage.html     Interactive coverage checker, postal code search & live zone availability
- dashboard.html    Subscriber dashboard (pay bills online, view active plans/upgrades, raise & track complaints, run live speed diagnostics)
- login.html        Subscriber login portal with quick demo login & access to dashboard
- signup.html       New connection application form with pre-selected plan parameters
- services.html     High-speed broadband, cable TV packages, and FTTH infrastructure overview
- about.html        Company profile, network mission, and values
- support.html      Help centre, FAQs, and subscriber support
- contact.html      Contact form and customer care details

Key Enhancements & Features:
1. Subscriber Dashboard (dashboard.html):
   - Current bill payment with interactive checkout modal (UPI / Card / NetBanking) and instant paid receipt generation
   - Active plan overview with 1-click plan upgrades and booster add-ons (+200GB, Sports HD, Static IP)
   - Real-time complaint registration form with live status timeline (Logged -> Assigned to Engineer -> Resolved)
   - Interactive live broadband speed test with simulated ping, download, and upload telemetry
2. Network Coverage (coverage.html):
   - Interactive PIN code and area availability search with real-time feedback
   - Active fiber hub zones with installation timelines
   - RWA / Society network expansion request form
3. Navbar Updates:
   - Login link removed from navlinks
   - "Sign up" styled as a prominent button placed next to the theme toggle button at the far end of the navbar
   - Direct access to Dashboard and Coverage from the main navigation
4. Light / Dark theme toggle and RTL (Right-to-Left) direction toggle with localStorage persistence
5. Fully responsive on desktop, tablet, and mobile screens

HOW TO RUN:
1. Extract the ZIP archive.
2. Open index.html in any modern web browser (or use VS Code Live Server).
3. Access the Subscriber Portal via login.html or directly open dashboard.html.
